# Support

Report bugs and feature requests in [GitHub Issues](https://github.com/jiahuei/ios-talking-clock/issues).

The original interval-clock implementation is archived in `v0/`. The new AlarmKit application requires iOS 26+. See the [specification](docs/SPEC.md) and [development guide](QUICKSTART.md) for scope and current setup. If a save fails, use Retry sync to finish the pending change. Enable alarm access in system Settings if it was denied, then enable your alarms again.

For alarm reports, include the app/iOS version, device model, whether the device was locked, permission state, repeat pattern, and whether the sound was a preview or a scheduled alarm. Avoid posting personal alarm labels.
